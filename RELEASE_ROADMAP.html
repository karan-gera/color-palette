PalettePort release roadmap

The product already exceeds an MVP. The remaining work is release hardening: correctness, honest public claims, dependency and failure handling, constrained-device startup, offline boot, and repeatable release gates.

Source of truth: TODO.md. Controls on this page filter and copy tasks; they do not change project state.

Decision

MVP

Smallest scope that validates whether the product is useful. PalettePort is already beyond this. Do not create a separate MVP milestone.

Public alpha

External testing with known limits. No known P0 correctness, security, legal, accessibility, or false-claim defect. Stored formats may still change.

Public beta

Feature scope frozen for v1. Constrained-device, offline, and compatibility gates pass. Remaining changes are bug fixes.

v1

Stable URL, version, support scope, release notes, and operational checks. No known high-severity release issue.

Recommended next target: desktop-only public alpha after the 12 alpha tasks close. Alpha may omit offline boot only if the app stops claiming it works offline.
